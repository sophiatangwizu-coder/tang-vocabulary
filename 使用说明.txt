TANG 词汇库 使用说明

一 开始使用
电脑：解压发布包，用 Chrome、Edge、Firefox 或 Safari 打开 index.html，无需联网。
手机和平板：推荐访问发布后的网址。部分系统的文件预览器不支持脚本或本机存储；如本地文件不能操作，请改用浏览器访问发布网站。
学习记录只在当前浏览器保存，打开网页时提示到期复习。关闭网页后不会发通知。不同浏览器、文件位置、网站地址之间不自动同步，请导出备份后迁移。

二 词库与导入
词汇简析73 包含 Test 01 至 Test 73，短语和整句分别标注。搜索支持中英文和部分匹配。
词库中的复选框支持跨分类挑选，或新建任务时按 Test 批量选择。
下载“词库导入模板.docx”，按最简单格式填写：第一行是大分类名称，Test / Unit / Lesson / Chapter 标题自动成为小分类，其他每行写一个词条，例如“1. daily routines 例行日常”。英文在前、中文在后；也支持中文在前、英文在后。保存为 docx 后导入，预览并确认写入。旧版 `.doc` 需先另存为 `.docx`。旧版七列表格模板仍兼容。
编辑词条时可以修改中英文、补充完整答案和备注。内置词条可恢复为当前发布版本原文；已有任务保存独立内容快照。
原文包含少量疑似错误或提示性写法，已保留原文并在相应备注中标注。多表达的自动判分仅作辅助；请核对实际表达，不要把未经核实的近义句直接加入答案。

三 背诵与复习
每张卡翻面后如实选择“没记住”“有点模糊”“记住了”。连续两次记住完成该卡；模糊或遗忘会清零。
双向模式每次随机展示中文或英文，两方向合并计算掌握次数。空格翻面，数字 1 / 2 / 3 评分。
全部卡片首次完成后才开始安排复习。初次间隔：曾遗忘 1 天，只有模糊 2 天，一直记住 4 天。
后续采用 1、2、4、7、15、30、60 天的间隔阶梯。遗忘回到 1 天，模糊退一级，全程记住进一级。按浏览器本地日历日期判断到期。
到期复习只包含到期卡和待纠错卡，错题优先；整轮完成后计算下次日期。中途离开可续背，逾期不堆积重复任务。

四 小测试
首次背诵完成后可以测试。默认 24 个计分项，支持 20—25 个；范围不足时减少，不重复凑数。
匹配每一对独立计分。选择与判断使用同范围内不冲突的答案作为干扰，无法产生适当选项时改用英文书写。
提交后显示参考答案；80% 及以上通过。英文判分接受已登记表达及部分括号和单词级斜杠变体，统一大小写、空格、弯引号及句末标点，不忽略拼写、词序和语法错误。
如表达正确但未收录，可自行改判。补充答案必须再次确认；仅明确补充的表达会同时进入词库、原任务及该道测试题。
错题进入原任务的优先复习队列，改判撤销该次错误。复习完成的旧错题不会因查看结果再次加入。

五 默写
默写不要求先完成背诵。打开“默写练习”后，直接按大分类和 Test 选择题库范围，设置题目数量和方向：中到英、英到中，或双向转换（中到英约 80%，英到中约 20%）。生成后题目和顺序固定。
预览题目只显示题目，不显示答案或横线；可以全屏打开、调整字号并上下滚动，适合投屏让学生在纸上作答。
学生版按题目方向显示提示并提供书写空白，整句提供两行；教师版附对应答案和可接受表达。均为真正的 Word docx 文件。纸笔默写不自动计分或记录错题。

六 备份与恢复
“导出完整备份”包含词库、网站设置、任务、进度、复习日程、测试、错题与默写。
“恢复备份”先检查数据，展示摘要，再整体替换当前记录。恢复前请下载当前备份。
定期备份，尤其在清理浏览器、更换文件路径或设备前。隐私模式中学习记录可能在窗口关闭后消失。保存失败会显示明确提示，此时先导出备份。

七 生成网站发布包
先保存网站名称与机构名称，点击“生成网站发布包”，核对摘要后下载 ZIP。
发布包把所有有效内置词条、本机导入内容及编辑结果作为新版内置词库。它只含教学内容和网站信息，不含任何人的任务、成绩或错题。
ZIP 内有 index.html、词库导入模板.docx、使用说明.txt。先解压，再打开网页；发给学生后无需重新导入。
新发布网页仍可继续编辑、导入和再次生成发布包。发布操作不自动上传 GitHub，也不修改当前数据。
同一浏览器站点更新网页时会保留本机学习记录，本机词条修改优先于新内置版本；已有任务维持原有快照。恢复原文会采用当前发布版本内容。

八 发布到 GitHub Pages
1. 在自己的 GitHub 创建用于网站的仓库。
2. 将 ZIP 解压后的 index.html、模板和说明上传到仓库根目录；不要只上传 ZIP。
3. 打开仓库 Settings → Pages，选择 Deploy from a branch，分支选择 main，目录选择 / (root)，保存。
4. 等待 GitHub 部署完成，打开 Pages 显示的网站地址，即可发给学生。
5. 以后用新发布包的文件替换仓库中对应文件，即可更新网站。
每个学生在自己的浏览器里保存学习记录。静态网页没有教师后台或云端同步；上传公开仓库的词库会对访问者公开。
